# ADVENT 31 / 2026

Интерактивный корпоративный Advent-календарь на **1–31 декабря 2026 года**.

Визуальная система собрана кодом: графитовый/чёрный фон, кислотный лайм, крупная постерная типографика и экспериментальные декоративные формы. Изображение-референс в страницу не вставляется.

Внутри — 31 мемное и мотивирующее сообщение для офиса, производства и команды. Будущие дни закрыты по дате, открытые запоминаются в localStorage. «Режим проверки» временно открывает все карточки для тестирования до декабря.

Адаптивная сетка: desktop, планшет и мобильный экран. Проект статический и готов для GitHub Pages.
