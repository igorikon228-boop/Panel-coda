# ADVENT 2026

Интерактивный Advent-календарь на 1–24 декабря 2026 года.

- 24 интерактивных окна;
- будущие даты заблокированы;
- открытые окна запоминаются в localStorage;
- отдельные шуточно-бодрящие пожелания на каждый день;
- адаптивная сетка для компьютера, планшета и телефона;
- режим проверки позволяет до декабря протестировать все окна;
- статический проект, готовый для GitHub Pages.

Откройте `index.html` или включите GitHub Pages для ветки `main`.
